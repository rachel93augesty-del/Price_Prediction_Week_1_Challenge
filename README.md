# Financial News & Stock Price Prediction Project

## 📊 Project Overview
A comprehensive system that combines financial news sentiment analysis with technical stock analysis to build predictive models for stock price movements.

## 🚀 Features
- **Technical Analysis**: RSI, Moving Averages, MACD, Bollinger Bands
- **Financial Metrics**: Returns, Volatility, Sharpe Ratio, Maximum Drawdown
- **News Sentiment Analysis**: Basic sentiment scoring and topic modeling
- **Data Visualization**: Interactive dashboards and comprehensive charts
- **Machine Learning Ready**: Feature engineering for prediction models
